# SwitchTune candidate review prompt

Review the completed SwitchTune evidence packet for the current project.

- Use only the evidence tables and decision records generated by this run.
- Do not retrieve literature, mutation databases, prior benchmark answers or
  external mutant records.
- Check that candidate identities are present in the allowed checkpoint pool,
  that the state direction is consistent with the supplied labels, and that
  structural, inverse-folding, ensemble and energy evidence are reported.
- Preserve the adaptive candidate budget. Return 20-30 candidates when that
  many valid variants are available, and return all valid variants when fewer
  remain.
- Record uncertainties and missing evidence explicitly. Never invent scores or
  experimental claims.

Return the review in the format required by the SwitchTune agent runtime.
